# gdk-portfolio

Personal site of Güngör Deniz Karataş. A single Angular app.

- All copy and project data: `src/app/content.ts`
- Images, icons and the CV PDF: `public/`
- Deploys to GitHub Pages on every push to `main` (`.github/workflows/deploy.yml`)

```bash
pnpm install
pnpm start      # http://localhost:4200
pnpm exec ng build
```
